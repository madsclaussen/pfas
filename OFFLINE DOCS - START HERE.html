Quick help without opening docs

  • In a notebook cell: cv2.findHomography? shows the docstring. Use ?? to see the source (for Python code).
  • help(o3d.pipelines.registration.registration_icp) prints the full signature and description.
  • In VS Code: hover over a function for its docstring, or press Ctrl+Space inside the brackets to see parameters.
  • dir(cv2) or [n for n in dir(cv2) if 'calib' in n.lower()] finds function names.
